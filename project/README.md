# Hostility in AITA comments

Comments from the Reddit forum r/AmItheAsshole, where people describe a conflict and ask strangers whether they were in the wrong. Each row is one reply, from 2019.

- `data/working_100.csv`: 100 comments to work with.
- `data/heldout_100.csv`: 100 other comments, kept aside for testing.
- `data/coder_5.csv`: 5 comments for a warm-up.

Columns: `id`, `text`, and `hostile`: our hand-coded label for "is this comment hostile or insulting toward someone?" (yes or no).
